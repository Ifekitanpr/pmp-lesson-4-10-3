# Lesson 4.10.3 — Illustration prompts

All assets use a clean Storyset-inspired flat editorial style, a pure white background, generous negative space, and only the lesson brand palette: vivid blue, deep navy, bright orange, white, and restrained cool grey. No borders, gradients, shadows, decorative text, or unrelated objects.

1. `01-hook.png` — A smoke detector sends an alert to a project manager; a clear acknowledgment path and an escalation path make the closed-loop safety-system metaphor immediately understandable.
2. `02-hook-modal.png` — A project communication travels from sender to receiver, returns as meaningful feedback, and changes the next message.
3. `03-enabler.png` — A project manager deliberately connects team members and stakeholders through an interactive feedback loop rather than a one-way broadcast.
4. `04-enabler-modal.png` — A communication-plan document with a visible closed-loop workflow connecting the project manager, team, and stakeholders.
5. `05-cycle-overview.png` — One coherent four-stage communication cycle: send, acknowledge, feedback, adjust.
6. `06-send.png` — A project manager chooses and sends a communication through the method that fits the message.
7. `07-acknowledge.png` — A stakeholder acknowledges a received project message inside a clearly defined timeframe.
8. `08-feedback.png` — A stakeholder explains their actual interpretation, revealing the difference between receipt and understanding.
9. `09-adjust.png` — A project manager refines the next communication after reviewing stakeholder feedback.
10. `10-patterns-overview.png` — Four distinct audience-fit feedback patterns arranged as a coherent communication ecosystem.
11. `11-pulse.png` — A short two-question pulse check feeds a trend dashboard across repeated briefings.
12. `12-decisions.png` — A steering committee report highlights a decision-needed item with a deadline and a visible escalation path.
13. `13-retrospective.png` — A project team retrospective surfaces what information people did not hear in time.
14. `14-vendor.png` — A vendor acknowledges a critical SLA notice while a responsiveness KPI is visibly tracked.
15. `15-guardrails-overview.png` — Three plan guardrails: escalation, confidential-release authority, and deliberate plan refresh.
16. `16-escalation.png` — An unanswered project decision moves through direct follow-up, sponsor escalation, and steering escalation.
17. `17-authority.png` — A named authorized person releases sensitive information through an approved secure channel.
18. `18-evolution.png` — A communication plan is deliberately refreshed at a phase gate as a new stakeholder group joins.
19. `19-exam.png` — A smoke-detector signal becomes a full communication feedback loop with acknowledgment, understanding, adjustment, and escalation.
20. `20-exam-modal.png` — A concise synthesis of the feedback-loop system: four-part cycle, audience-fit patterns, escalation, authority, and refresh triggers.
